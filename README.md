**Hamro Hotel**
A simple hotel website and order management system built with PHP, HTML, CSS, and JavaScript.This project provides basic hotel functionality including browsing food categories, user registration/login, food ordering, cart management, and contact support.

**🚀 Features**

    ✔ Home page with featured foods  
    
    ✔ User authentication (Sign Up / Login / Logout)  
    
    ✔ Food categories and listings  
    
    ✔ Add to cart & cart display  
    
    ✔ Take and place orders  

    ✔ Contact form for customer messages  
    
    ✔ Basic PHP & MySQL backend

**🛠 Tech Stack**

    PHP– server-side logic  
    MySQL– database backend  
    TML / CSS– front‑end structure and styling  
    JavaScript– interactive behavior

**📦 Requirements**

To run locally, ensure you have:

    ✔ PHP (7.0+)  
    ✔ MySQL or MariaDB  
    ✔ A local server environment (XAMPP, WAMP, MAMP, etc.)

**🧩 Installation**


**Clone the repository:**
  
    git clone https://github.com/bibekdhakal01/Hamro_Hotel.git
    Move the folder into your web server directory (htdocs or www).
    
    Start your local server and create a database (e.g., hamro_hotel_db).
    
    Import the SQL schema (if available) or create required tables manually.
    
    Update connect.php with your database credentials.

**🛠 Usage**

    New users can register under Sign Up
    
    Login with registered credentials
    
    Browse foods & add to cart
    
    Place an order
    
    Use Contact page to send messages

**❓ Troubleshooting**

If something isn’t working:

    Check database connection settings
    
    Ensure the server has proper PHP & MySQL support
    
    Verify file permissions
